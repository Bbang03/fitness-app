# 운동 안내 영상 처리 작업 기록

## 목적과 범위

운동 안내용 해부학 스타일 GIF를 여러 개씩 처리하고, 기존 근육 강조색을
빨간색으로 변경해 짧은 반복 재생용 MP4 후보를 제작했다. 이후 점무늬 노이즈
완화와 밝은 배경 정리를 추가했다.

이 문서는 팀원에게 별도로 전달한 영상 처리 코드와 로컬 검증 결과를 기록한다.
이 커밋에는 문서만 포함하며, 처리 코드·원본 GIF·결과 영상이 이 저장소에
통합되었다거나 실제 앱에 배포되었다는 뜻은 아니다.

## 입력과 출력

- 입력: 팀에서 준비한 운동 GIF 36개. 모두 500×500 해상도이며 길이는 약 4.93~8.13초다.
- 기본 출력: H.264 / yuv420p / 무음 MP4, faststart 적용.
- 원본 프레임 수와 가변 프레임 표시 시간을 유지한다. 중간 프레임을 새로 생성하지 않는다.
- 출력 해상도는 500×500으로 유지한다. 원본과 이전 결과는 보존하고 버전별로 별도 저장했다.
- 이름만으로 종목별 사용 근육을 확정하지 않는다. 가슴 운동 모음에도 다른 부위 중심 종목이 포함될 수 있다.

## 처리 과정

1. 폴더 또는 ZIP의 입력을 등록하고 파일 해시·영상 정보를 검사한다.
2. 원본을 프레임과 표시 시간으로 디코딩한다.
3. 기존 파랑·청록 강조 영역을 선택해 빨간색으로 변환한다.
4. 선택 설정에 따라 약한 점무늬 완화를 적용한다.
5. 흰 배경 버전은 밝고 색 차이가 작은 영역 중 화면 가장자리 주변과 연결되는 배경 후보를 정리한다.
6. MP4로 인코딩한 뒤 전체 디코딩, 프레임 수·시간·형식 검사를 수행한다.
7. 비교 이미지, 기술 QA, 체크섬과 실행 기록을 남긴다.

완료 여부는 파일 존재만으로 판단하지 않고 설정·입력·결과 해시를 확인한다.
동일 작업 재실행 시 유효한 결과를 재사용하도록 기본 일괄 처리 파이프라인을 구성했다.

## 화질 보정에서 확인한 문제

GIF의 회색 영역에 섞인 파랑·노랑 점을 단순 색상 필터가 근육 강조로 오인할 수 있었다.
이를 줄이기 위해 색상 선택에는 주변 평균색과 색 차이 기준을 사용했다.

점무늬 완화 버전은 색상 변환 후 다음 설정을 적용했다.

- Gaussian blur radius: 0.55
- Unsharp mask: radius 1.0, percent 40, threshold 3
- H.264 CRF: 18

흰 배경 버전은 주변 색상 판정, 전경 주변 보호 여백, 연결 영역 검사를 추가했다.
배경으로 선택하지 않은 부분은 이 단계에서 인코딩 전 픽셀이 바뀌지 않는지 검사했다.
회색 로고와 기구·인체 경계는 보호 대상으로 취급하며 로고 제거 기능은 넣지 않았다.
다만 H.264는 손실 압축이므로 최종 영상의 모든 픽셀이 원본과 동일하다는 뜻은 아니다.

## 실제 36개 처리 결과

2026-09-14 로컬 macOS ARM64 CPU 환경에서 측정했다.

| 처리 버전 | 완료 영상 | 전체 처리 시간 |
|---|---:|---:|
| 빨간색 강조 변환 | 36개 | 190.72초, 약 3분 11초 |
| 점무늬 완화 추가 | 36개 | 269.83초, 약 4분 30초 |
| 점무늬 완화 + 흰 배경 정리 | 36개 | 342.81초, 약 5분 43초 |

환경: Python 3.12, PyAV 15.1.0, Pillow 12.3.0, NumPy 2.3.5.
시간에는 프레임 처리·인코딩·기술 검사·비교 자료 생성 등을 포함한다.
개발 시간, 최초 라이브러리 설치, Drive 업로드와 사람의 검토 시간은 제외한다.
종목 구성과 기기 상태에 따라 달라지며 Colab이나 실제 서비스의 보장 속도가 아니다.

이 결과는 **생성 모델 추론을 생략한 CPU 색상 변환·후처리**다.
기존 VACE 영상 재생성과 같은 작업의 속도가 수백 배 개선되었다는 의미가 아니다.
선택형 VACE 경로는 별도 코드에 포함했지만 실제 Colab GPU 추론은 이 검증에 포함하지 않았다.

## 업스케일을 기본값으로 선택하지 않은 이유

벤치프레스·덤벨 플라이·푸시업을 두 번씩 비교했을 때, 1.5배 확대와 약한 선명화는
기존 대비 약 1.99배, 2배 확대와 약한 선명화는 약 2.79배의 처리 시간이 걸렸다.
점무늬까지 강조되는 현상이 있어 전체 일괄 처리의 기본값으로 적용하지 않았다.
확대 해상도 자체가 새로운 해부학 디테일의 복원을 의미하지 않는다.

## 앱 반영 전 확인할 사항

- 색상 선택은 근육 인식 모델이 아니다. 기존 강조 부위를 바꾸는 기능이며 새 근육 위치나 활성도를 추론하지 않는다.
- 해당 운동의 자세와 주동근·보조근 표시를 사람이 검수해야 한다.
- 자동 검사 통과는 해부학 정확성이나 안전성 승인과 다르다.
- 점무늬 완화는 미세한 선도 부드럽게 만들 수 있다. 영상 전체의 경계·깜빡임·반복 이음새를 확인해야 한다.
- 실제 모바일 기기에서 재생과 용량, 화면 표시 크기를 검토해야 한다.
- 원본의 수정·배포 권한은 별도 확인해야 한다. 색상 변환, 배경 정리 또는 AI 재생성이 이용 권한 문제를 자동 해결하지 않는다.
- 원본 GIF와 검토용 결과물은 이 문서 커밋에 포함하지 않는다.
